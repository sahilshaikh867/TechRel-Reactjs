# API Integration Lab — 02 API Basics

## What is an API?
An API is a contract that lets one software system communicate with another.

```text
React UI → HTTP Request → API Server → JSON Response → React State → UI
```

## HTTP methods

| Method | Purpose |
|---|---|
| GET | Read |
| POST | Create |
| PUT | Replace/update |
| PATCH | Partial update |
| DELETE | Delete |

## Example endpoint
```text
GET https://jsonplaceholder.typicode.com/users
```

## Common status codes
- 200 OK
- 201 Created
- 204 No Content
- 400 Bad Request
- 401 Unauthorized
- 403 Forbidden
- 404 Not Found
- 429 Too Many Requests
- 500 Server Error

## Important terms
Endpoint, request, response, headers, body, query parameter, path parameter, JSON, authentication, authorization and rate limit.
